# Frequently Asked Questions (FAQ)

**Author**: Ankur Gaurav

### Q: What is OmniForge?
A: OmniForge is an enterprise Model Context Protocol (MCP) framework created by Ankur Gaurav to unify AI skills, prompts, workflows, and multi-client IDE integrations.

### Q: Which AI clients are supported?
A: Claude Desktop, Cursor IDE, VS Code, OpenAI Codex, ChatGPT Actions, Google Gemini, and Google Antigravity.
