# OmniForge API Reference

**Author**: Ankur Gaurav

---

## Core Classes (`@omniforge/core`)
- `ConfigManager`: Manages workspace `.omniforge/config.json`.
- `Logger`: Structured file and stdout logger.
- `TelemetryService`: Anonymous diagnostic collector.
- `PluginLoader`: Dynamic plugin engine.
- `UpdateManager`: Version & update manager.

## Client SDK (`@omniforge/sdk`)
- `OmniForgeClient`: High-level client for MCP server communication.
