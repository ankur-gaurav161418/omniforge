# OmniForge 5-Minute Quick Start Guide

**Author**: Ankur Gaurav (https://github.com/ankur-gaurav161418)

---

## Step 1: Install OmniForge CLI
```bash
npm install -g omniforge
```

## Step 2: Run Diagnostic Check
```bash
omniforge doctor
```

## Step 3: Initialize Workspace
```bash
omniforge init
```

## Step 4: Install MCP Integrations into your IDE
```bash
omniforge install --all
```

## Step 5: Start Production MCP Server
```bash
npm run mcp:start
```
