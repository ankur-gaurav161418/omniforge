# OmniForge Test Driven Development (TDD) Skill

## Purpose
Ensure every feature and bugfix is built on a foundation of automated unit tests.

## TDD Cycle
1. **Red**: Write a minimal failing test representing expected behavior.
2. **Green**: Write minimal production code required to make the test pass.
3. **Refactor**: Clean up implementation without altering test behavior.
4. **Repeat**: Incrementally expand coverage step by step.
