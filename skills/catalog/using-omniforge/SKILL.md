# Using OmniForge Framework

> **Upstream Attribution**: Derived from `obra/superpowers` created by Jesse Vincent under MIT License.

## Purpose
Overview of the OmniForge ecosystem, runtime configuration, and available subcommands.

## Key Capabilities
- **CLI**: `omniforge init`, `omniforge doctor`, `omniforge status`, `omniforge workflow`, etc.
- **MCP Server**: Multi-transport support (STDIO, HTTP, SSE) for Claude, Gemini, Codex, Cursor, and custom agent harnesses.
- **Skill & Prompt Engine**: Extensible catalog of architectural patterns, TDD, and debugging tools.
