# OmniForge Brainstorming & Architectural Design Skill

## Purpose
Guide AI agents and human engineers through structured interactive design sessions before jumping straight to code implementation.

## Workflow Phases
1. **Understand Requirements**: Solicit user intent, problem domain, and functional goals.
2. **Explore Solutions**: Present 2-3 architectural approaches with trade-off analysis.
3. **Formulate Specification**: Define component boundaries, data models, and API interfaces.
4. **Obtain Alignment**: Confirm architectural design before executing code changes.

## Best Practices
- Never assume requirements without asking targeted questions.
- Prefer minimal, robust, modular designs (SOLID & Clean Architecture).
- Document design decisions in an architectural decision record (ADR).
